# 🐸 Flexbox Froggy Solutions

Welcome to the **Flexbox Froggy Solutions** repository! This repo contains all the correct answers (CSS code) for each level of the popular game [Flexbox Froggy](https://flexboxfroggy.com/), which is a fun and interactive way to learn CSS Flexbox layout.

## 🎯 What is Flexbox Froggy?

Flexbox Froggy is an educational game designed to teach you the basics of CSS Flexbox through interactive levels. In each level, you help Froggy and friends by writing CSS that positions them correctly on a lily pad grid.

Created by Thomas Park at [Codepip](https://codepip.com/), the game is free to play and a great way to reinforce Flexbox concepts.
